## 🛠️ Kullanılan Teknolojiler ve Araçlar

Proje geliştirilirken aşağıdaki teknoloji, kütüphane ve mimari yapılar tercih edilmiştir:

* **Framework:** ASP.NET MVC 5
* **Dil:** C# (.NET Framework)
* **Veritabanı Yönetimi:** Microsoft SQL Server & Entity Framework (Database First / Code First yaklaşımı)
* **Arayüz (Frontend):** HTML5, CSS3, Bootstrap, JavaScript / jQuery
* **IDE:** Microsoft Visual Studio

---

## ⚙️ Özellikler ve Modüller

Proje temel olarak 5 ana modül üzerine kurulmuştur:

1. **📦 Ürün İşlemleri:** 
   * Ürün listeleme, arama ve sayfalandırma (pagination).
   * Yeni ürün ekleme, mevcut ürün bilgilerini güncelleme ve silme.
   * Ürünlerin fiyat, stok, marka ve kategori bilgilerinin takibi.

2. **🏷️ Kategori Yönetimi:**
   * Ürünlerin ait olduğu kategorilerin listelenmesi ve yönetimi.
   * Yeni kategori ekleme, güncelleme ve silme işlemleri.

3. **👥 Müşteri Yönetimi:**
   * Müşteri kayıtlarının tutulması, ad/soyad bazlı arama işlemleri.
   * Müşterilere özel dinamik bildirim (`Alert`) alanları ve yönetim butonları.

4. **💰 Satış İşlemleri:**
   * Modal (açılır pencere) tasarımı üzerinden ürün, müşteri, adet ve fiyat bilgileri girilerek hızlı satış yapabilme imkanı.

5. **📊 Veritabanı Entegrasyonu:**
   * İlişkisel veritabanı tabloları arasında Foreign Key ve Join sorgularının etkin kullanımı.
